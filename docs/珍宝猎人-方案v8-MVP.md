## 〇、一句话概述

**玩家带着一笔星际币穿越到 LLM 现场生成的异世界集市（该世界有自己的物价水平），在"高仿可能高价、珍品可能低价"的信息迷雾中砍价买下 5 件 3D 珍宝，可向随行的鉴宝精灵请教情报（它懂行但不知价、更不知真伪；询问额度按等级发放，初始 5 次/关），回基地鉴宝回收——真伪由 Lux3D 生成的 3D 模型特征对照"创作人真品规范"来判定，赚差价升级出价与询问额度，再去更险更贵的世界。**

四个 AI 的分工（全部体现为可感知的玩法）：

| AI 环节 | 职责 | 玩法体现 |
|---|---|---|
| DeepSeek（玩家自配 Key） | 生成异世界、创作人、珍宝档案、价格、摊主人设 | 每局内容全新、无重复关卡 |
| DeepSeek · 鉴宝精灵 | 持世界级知识答问（防火墙内） | 信息也是资源：问什么、何时问，是策略 |
| Lux3D 文生3D（玩家自配 Key） | 按程序组装的 prompt 生成每件珍宝 GLB | 玩家亲手转动检视的就是 AI 生成物，判定依据藏在模型里 |
| 本地确定性代码 | 砍价数值判定、特征核对、收益结算 | 游戏永远公平、可复现、无随机翻脸 |

## 一、技术前提实测结论（2026.11.15，全部真实调用）

### 1.1 纯网页可行性：✅ 成立，零后端

| API | CORS 实测 | 鉴权 | 结论 |
|---|---|---|---|
| DeepSeek `api.deepseek.com/chat/completions` | `access-control-allow-origin` 回显请求源；allow-headers 含 `authorization,content-type`；allow-methods POST | `Authorization: Bearer <sk-...>` | **浏览器直连可行** |
| Lux3D `api.aholo.cn/lux3d/v1/*` | 预检 `access-control-allow-origin: *`；错误响应可能无 CORS 头（见排障） | `Authorization: <API Key>`（**无 Bearer 前缀**，加了反而 invalid） | **浏览器直连可行（需有效 Key / 地区）** |

两个 API 都开放 CORS → **单页静态站即可运行**，玩家在设置页填入 DeepSeek Key + Lux3D Key（存自己浏览器的本地存储），即玩。Key 不经过任何服务器。

### 1.2 成本与耗时实测

- **文生3D G1-Turbo 单件 13 积分**（询价 quote_046bcdc617af46a3bfdd13493ebb7d46；faceCount 100000、GLB+PBR）。一关 5 件 = **65 积分**；余额 3300 ≈ **50 关**。玩家自配 Key，成本可控且透明（设置页显示"本局将消耗约 65 积分"）。
- **G1-Turbo 单件耗时 90~135 秒**（实测任务 8007288）。免费档并发 5 → 一关 5 件并行 = **约 2~3 分钟一关**，与"读世界观 + 认识创作人"阶段错峰后基本无感。
- **产物验证**：GLB v2 有效，单件约 13MB（PBR 贴图为主）→ **验货时按需加载单件**，一次只进一件。
- DeepSeek 单关消耗：1 次大调用（整关 JSON）+ 精灵简报（并入大调用）+ ≤5 次精灵问答小调用 + 砍价小调用 ≈ 每关几分钱。

## 二、设计漏洞分析（15 项）与修复方案

> 按严重程度排序。**H = 不修复则玩法不成立；M = 不修复则体验/数值崩坏；L = 打磨项。**

### H1. 判定依据缺失——玩家凭什么判断真伪？（致命）

**问题**：真伪、真实价值全由 LLM 生成，但玩家没有可核对的信息源。若玩家只能看价格和文案猜真假，游戏退化为抽奖。

**修复**：**判定依据 = "创作人真品规范" 对照 3D 实物特征**（v7 对档案内核的 MVP 化）：
- 每个创作人有一份**真品规范**（signature traits，如"星纹宝石恒为七颗、晶体恒为青蓝色、底座恒为银色"），在穿越阶段随世界观一起展示。
- 每件珍宝标注署名创作人；3D 模型呈现**实际特征**。
- 仿品 = 署名是某创作人，但特征偏离其规范（多一/少一/换色/换形，来自混淆算子）。
- **判定铁律继承 v7：不多不少。多一也是仿**（做得"太满"的高仿最优雅）。
- 特征白名单只用粗粒度项：**色族、计数（≤7 的小数目）、形制、有无**。禁用纹理间距、笔触类文生3D 渲染不稳的项。

### H2. "购买完所有珍宝" + 资金无限 = 全买零风险（致命）

**问题**：如果玩家总能买下全部珍宝，就无需鉴别。

**修复**：**双闸门**——
1. **资金即预算**：初始 1000 星际币，珍宝标价之和刻意高于资金（LLM 生成时约束 `Σ标价 ∈ [1.5, 2.2] × 资金`），必须取舍。
2. **出价额度**：初始 10 点/关（每级 +5），每次报价消耗 1 点。
3. "购买完所有珍宝"改写为**「主动收摊」**（收摊按钮）+ 自动结束条件（额度耗尽或资金低于全场最低底价）。

### H3. 砍价由 LLM 自由判断 → 无底价意识 + 判定不稳定（高）

**修复**：**混合判定——硬规则守数值，LLM 管态度和台词**：
1. 前端硬校验：报价 < bottomPrice → **必拒**（不问 LLM）。
2. 报价 ≥ bottomPrice：LLM 做态度判定，输入为**结构化上下文**（flexibility、报价/标价比、已砍回合数），输出 `{"accept":bool,"line":台词}`，前端做一致性兜底（同件第 N 次接受价 ≥ 第 N-1 次拒绝价）。
3. 摊主 `bottomPrice`/`flexibility` 在关卡生成时结构化产出，前端持锁。
4. 设置页提供"快速模式"：纯本地公式判定 + 预生成台词池。

### H4. 鉴宝时再问 LLM → 真伪可能翻供（高）

**修复**：**真伪在生成时刻即定死**——`isAuthentic` 由 `tamperOp == null` 程序推导并覆写，非 LLM 宣称。鉴宝环节只**揭晓**该字段 + 展示「实际特征 vs 真品规范」的 diff 对账。全程 LLM 无法事后改口。

### H13.（v8.1 新增）精灵泄底——知道得太多就是作弊器（致命）

**问题**：精灵由 LLM 驱动且"主动了解整个故事背景"——若把整关 JSON（含 isAuthentic/trueValue/tamperOp）喂给它，玩家一句"哪件是正品？"（≤50 字绰绰有余）就能通关，游戏崩盘。

**修复：信息防火墙——精灵不知道的，是它真的不知道（物理隔离，不是口头承诺）**：
1. **精灵的运行时上下文只含三样**：世界背景（lore/居民偏好/物价氛围）、创作人档案（生平/档位/**真品规范**——本就是公开信息）、本世界盛行的做伪手法（**类型级**，如"流行改颗数和换釉色"，不含单件归属）。
2. **单件珍宝的一切数据（真伪/篡改/实际特征/价格/底价）根本不进精灵的 prompt**——LLM 无法泄露它没有的信息。这同时天然满足"精灵不知道价格"的设定。
3. 被问及越界问题（"第 3 件是不是假的"）→ 精灵以角色口吻挡回（"我又没长天眼，你得自己凑近看"）。
4. 前端输出兜底过滤：答案中出现件数编号/编号样式（"第X件/T3"）时替换为挡回语。
5. **简报在关卡生成时一并产出**（`fairy.briefing` 字段，零额外调用），穿越阶段免费展示——"主动了解背景"体现为开场就递上一份三行情报简报。

### M5. 真实价值不可推断 → 利润预期无从建立（中高）

**修复**：三档**可推断信号**：创作人 `reputationTier` 行情区间 `quoteRange`、摊主 `savviness`（外行摊主的真品更可能标低价）、世界观行情氛围（含 v8.1 的物价指数提示，见 M15）。玩家综合信号估价——**"懂行"第一次有了回报**。

### M6. 手续费 + 仿品回收 = 双重亏损陷阱（中）

**修复**：真品回收价 = trueValue；仿品回收价 = 标价 × 0.1 工艺残值；回收手续费 = 固定 20 星际币/件；鉴宝逐件**免费**看真伪，回收与否逐件选择。MVP 工期紧时简化为一键全部回收。

### M7. 出价次数语义不明（中）

**修复**：明确为**每关独立的议价额度**，初始 10 点：每次报价消耗 1 点（含首次）；摊主还价不消耗；单件最多 4 回合（末回合拒绝即流拍，本关不可再议）。每级 +5 点。

### M14.（v8.1 新增）询问额度的边界与时机（中）

**修复**：精灵问答 = **每关独立额度，初始 5 次，每级 +2**；**仅集市阶段可问**（回基地后真相已揭晓，问无意义）；问题 ≤50 字（输入框计数硬限），回答 ≤100 字（max_tokens 截断，保持节奏）；穿越简报不占额度。一关 5 问 ÷ 5 件珍宝 = 平均每件 1 问的预算压力，与出价额度一样是"火力分配"决策。

### M15.（v8.1 新增）货币利差若等比放大 = 纯贴皮（中）

**问题**：若物价高的世界连真实价值也同比放大（买卖都 ×1.5），利润率不变，"利差"只是文案风味，玩家感知不到策略差异。

**修复：非对称利差模型**——
1. 每个世界有 `priceIndex ∈ [0.8, 1.6]`（LLM 按世界气质选，熔岩城邦贵、乡野集市贱），**只作用于标价与底价**（摊主按本地行情要价）；
2. **真实价值锚定创作人档位区间**（星际币计价的普世行情，不随本地物价膨胀）——高价世界 = 溢价更狠、砍价空间被压缩、误购高仿亏损更痛；
3. 补偿机制（防"高价世界=纯亏"）：高价世界 LLM 被约束倾向生成**更高档位创作人**（trueValue 绝对值抬升），高风险高回报；
4. 本地货币（烬金币、潮汐贝……）**纯风味**，所有数字统一显示星际币，避免双币换算的心智负担；
5. 世界 lore 里的物价氛围（"此地物贵，钱不经花"）+ 精灵简报提示 = 玩家可预判预算策略。
6. Σ标价约束（相对玩家资金）在物价指数施加后仍强制成立，且**单件标价 ≤ 玩家资金 × 0.9**（防止出现谁也买不起的死局）。

### M8. 等待体验：一关 2~3 分钟生成期（中）

**修复**：错峰设计——玩家点"穿越"后立即调 DeepSeek（30~60s），世界观文案先到先展；期间 5 个 3D 任务并行；3D 进度以「集市布展中」五格进度条呈现。**关卡数据 + GLB 全存 IndexedDB**：重开同关卡零积分重跑。

### M9. 关卡 JSON 可靠性（中）

**修复**：DeepSeek `response_format: json_object` + temperature 0.7 + prompt 内嵌 schema；前端手写校验 + 2 次定向重试；仍失败 → 错误提示 + 重掷按钮。

### L10. GLB 体积与加载（低）

13MB/件 → 验货单件按需 fetch + 「开箱雾」淡入；集市列表用纯 CSS 卡片。

### L11. 游戏结束条件缺失（低）

资金 < 全场最低底价 → "盘缠耗尽"结算：显示战绩，可软重开（保留等级，资金回 1000）。

### L12. 异世界多样性漂移（低）

本地**30 条种子库**（熔岩锻造城邦/浮游晶簇树海/深渊墨市/蒸汽齿轮港…）抽 1 条作为 `worldGenre` 硬参数传入，LLM 填血肉；物价指数区间也挂在种子上，防止 LLM 每次都选中庸值。

## 三、修复后的完整玩法循环（MVP 全量）

```
┌─ 集市阶段（每关） ──────────────────────────────────────┐
│ ① 穿越       种子抽异世界 → LLM 生成整关 JSON →         │
│              世界观/创作人规范展示 + 精灵三行简报（免费） │
│              （3D 并行生成中）                          │
│ ② 开市       5 件珍宝卡片（名称/署名/标价/摊主一句话）   │
│ ③ 验货       逐件 3D 检视（旋转/缩放/双击聚焦）          │
│              对照「创作人真品规范」核对特征              │
│ ④ 问精灵     集市阶段随时可问（5 次/关，问 ≤50 字）      │
│              创作人八卦 / 本世界做伪手法 / 世界背景      │
│ ⑤ 议价       报价滑条 → 摊主反应 → 成交/流拍            │
│              （额度 10 点/关，资金为预算闸门）           │
│ ⑥ 收摊       主动收摊 / 额度资金耗尽                    │
└─────────────────────────────────────────────────────────┘
┌─ 基地阶段 ──────────────────────────────────────────────┐
│ ⑦ 鉴宝       逐件揭晓真伪 + 特征 diff 对账（免费）       │
│ ⑧ 回收       逐件选择：付 20 星际币手续费 → 拿回收价     │
│ ⑨ 结算       净收益 = Σ回收 − Σ成交 − Σ手续费            │
│              经验涨 → 升级 → 议价额度+5 / 询问额度+2     │
│              → 难度+1                                   │
└─────────────────────────────────────────────────────────┘
```

**核心张力**（一句话讲给评委）：**你以为你在砍价，其实你在鉴定**——每一次报价都在暴露你对真伪与价值的判断；而精灵的存在让**"问什么"本身也成了策略**。

## 四、鉴宝精灵系统（v8.1 新增，MVP 全量实现）

### 4.1 人设与产出

- 精灵随关卡生成：`fairy.name`（如"鎏金"）+ `fairy.persona`（毒舌学者/絮叨老灵魂/傲娇幼龙，LLM 从池中选并贯彻）。
- 开场**三行简报**（免费，不占额度，`fairy.briefing` 随关卡 JSON 一并生成）：① 世界气质与物价氛围；② 创作人速览（谁最值得盯）；③ 本世界盛行做伪手法（类型级）。
- 运行时问答：独立 DeepSeek 调用，带上 §4.2 的防火墙上下文，输出 ≤100 字。

### 4.2 信息防火墙（系统设计核心）

| 信息 | 精灵是否有 | 说明 |
|---|---|---|
| 世界背景 / 居民偏好 / 物价氛围 | ✅ | 与玩家读到的同源，可展开细节 |
| 创作人生平 / 档位 / **真品规范** | ✅ | 规范本是公开档案，复述合法 |
| 本世界盛行做伪手法（**类型**） | ✅ | 知道"流行改颗数"，不知道哪件被改 |
| 任何单件珍宝的真伪 / 篡改 / 实际特征 | ❌ **物理隔离** | 不进 prompt，LLM 想泄也没有 |
| 任何价格（标价/底价/真实价值） | ❌ **物理隔离** | 天然符合"精灵不知价"设定 |
| 摊主议价弹性 | ❌ | 同上 |

**兜底**：越界问题以角色口吻挡回（prompt 指令）+ 前端输出过滤（答案含件数编号样式 → 替换为挡回语）。

### 4.3 问答的玩法价值（为什么值得花次数）

精灵答案能**收窄搜索空间**，但永远不直接给答案：
- "这个世界的仿品会加多余特征吗？" → 若 feature_add 未启用，答"没听说" → 玩家知道本关不必防"多一"；
- "格罗姆老爷子近年手抖吗？" → "他晚年作品颗数偶尔少一颗" → 暗示 count_change 风险（类型级）；
- "这世界最近缺什么？" → 行情氛围 → 价值推断的旁证。
**好的问题 = 少走弯路，坏的问题 = 浪费火力**——这正是"询问额度"作为资源的设计意义。

### 4.4 成本

简报 0 额外调用（并入关卡大调用）；每问 1 次 DeepSeek 小调用（上下文约 1.5k tokens，回答 ≤100 字，约 2 秒）——每关至多 5 问，成本忽略不计。

## 五、关卡数据协议（DeepSeek 唯一大调用）

一次 `deepseek-chat` 调用生成整关 JSON（约 2.5~3k tokens 输出，30~60 秒）：

```jsonc
{
  "world": {
    "name": "烬岩坊市",
    "genreSeed": "熔岩锻造城邦",          // 前端传入，LLM 只做血肉
    "lore": "约 200 字世界观短文",          // 含物价氛围（"此地物贵"）
    "residentPref": "本地匠人崇尚……",
    "priceIndex": 1.4,                    // ★ v8.1：物价指数 [0.8, 1.6]，只作用于标价/底价
    "currencyName": "烬金币"              // 纯风味
  },
  "fairy": {                              // ★ v8.1：鉴宝精灵
    "name": "鎏金",
    "persona": "毒舌学者",
    "briefing": ["烬岩坊市物贵，钱不经花。", "盯紧老锻翁，他的东西最近仿得凶。", "此地仿品惯用改颗数、换釉色。"]
  },
```

**关键工程决策（v7 原则的延续）**：
1. **renderPrompt 由前端程序从 `traits`（经 `tamperOp` 改写后）组装**，模板填空 → 特征与模型一一对应，判定可解。
2. `isAuthentic` 由程序覆写：`tamperOp == null ⇔ true`。
3. 价格由 LLM 在**约束区间**内生成（含物价指数指令），前端校验并 clamp。
4. 混淆算子白名单（LLM 为每件仿品选配）：
   - L1（难度1）：每仿品 2 个显性算子（color_swap + count_change）
   - L2：1 个中等算子（count_change 或 hasBase 翻转）
   - L3+：1 个微妙算子（count ±1）或真品数降至 1/5
   - `material_swap` MVP 不做，留作 post-MVP。
5. **精灵问答上下文在运行时由前端从关卡 JSON 抽取组装**（world + creators + 本关实际启用的 tamperOp 类型集合——不含任何 stalls 字段），防火墙由代码结构保证。

### renderPrompt 模板（示例）

```
A fantasy treasure: {shape} in {color} with {gemCount} small golden star gems
embedded around its equator, {hasBase ? "mounted on a dark silver metallic base" : "free-floating"},
faintly glowing, game asset style, clean studio lighting
```

即今天实测的那条 prompt——13 积分 / ~2 分钟 / GLB 有效。每件珍宝按 traits 填空生成。

## 六、经济数值表（MVP 定稿）

| 项 | 值 | 说明 |
|---|---|---|
| 初始资金 | 1000 星际币 | 软重开回 1000 |
| 每关珍宝数 | 5 件 | 真品 2~3 件（难度↑递减至 1） |
| 物价指数 | [0.8, 1.6] / 世界 | 只作用于标价/底价；真实价值锚定档位 |
| Σ 标价 | ∈ [1.5, 2.2] × 玩家资金 | 指数施加后仍强制；单件 ≤ 资金 × 0.9 |
| 议价额度 | 10 点 + 5/级 | 每关刷新；单件 ≤4 回合 |
| **询问额度** | **5 次 + 2/级** | 每关刷新；仅集市阶段；问 ≤50 字 / 答 ≤100 字；简报免费 |
| 底价 | [0.55, 0.75] × 标价 | LLM 生成，前端持锁 |
| 真品回收价 | trueValue | ∈ 创作人 quoteRange（普世锚） |
| 仿品回收价 | 0.1 × 标价 | 工艺残值 |
| 回收手续费 | 20 星际币/件 | 只对选择回收者收 |
| 经验 | 净收益（星际币数即经验） | 每 800 经验升 1 级 |
| 难度 | = 等级 | 仿品算子更微妙 + 真品数递减 |
| Lux3D 消耗 | 13 积分 × 5 = 65/关 | 设置页明示 + IndexedDB 缓存防重跑 |
| 游戏结束 | 资金 < 全场最低底价 | 结算战绩，可软重开 |

**赢利路径检验**（数值沙盘，物价指数 1.4 的贵世界）：1000 资金进贵世界 → 标价普遍溢价（单件 600+），只买得起 1~2 件 → 正确锁定 1 件真品并以底价附近砍下（~420）→ 回收 trueValue 780 − 手续费 20 ≈ 单件净赚 340；误购高仿 600 → 残值+手续费抵扣后净亏 520，**贵世界的错单惩罚几乎是贱世界的 1.4 倍**——物价指数真实地改变了决策重量，而非贴皮。

### DeepSeek 调用要点

- `POST https://api.deepseek.com/chat/completions`，`Authorization: Bearer <key>`
- 关卡生成：`deepseek-chat` + `response_format: {"type":"json_object"}`，system 内嵌 schema + 数值约束
- 精灵问答：普通模式 + max_tokens 200 + 防火墙上下文（代码组装，不含 stalls）
- 砍价判定：JSON 模式小调用

### Lux3D 调用要点

- create：`POST /lux3d/v1/generate/text-to-3d/task/create`，`Authorization: <key>`（无 Bearer），body 含 prompt/version=**G1-Turbo**/faceCount=100000/outputFormat=["glb"]/enablePbr=true
- 轮询：`POST /lux3d/v1/generate/task/get`，3s 间隔，status 3 = 完成
- 下载 GLB → blob 入 IndexedDB（结果 URL 仅 2 小时有效，即下即存）
- 并发 5 恰好一关 5 件
